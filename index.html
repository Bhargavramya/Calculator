GitHub Pages Hosting Guide

Follow these simple steps to host this calculator for free on GitHub Pages:

Step 1: Save as index.html

Make sure this single file is named exactly index.html.

Step 2: Create a GitHub Repository

Go to GitHub, create a new public repository (e.g., store-calculator).

Step 3: Upload the file

Upload or commit index.html directly to the main branch of your repository.

Step 4: Enable GitHub Pages

Go to your repository Settings > Pages. Under Build and deployment, set Branch to main (or master) and click Save.

Your app will be live at: https://your-username.github.io/repository-name/
